# Craftmentation Brand Guidelines

## Core identity
- Character: Minimal, technical, considered
- Accent: Yellow `#FBBF24`
- Dark: `#1F1F23`
- Light: `#F9FAFB`
- Neutral: `#6B7280`
- Typeface: Inter (use a system sans-serif fallback where Inter is unavailable)

## Symbol
The geometric mark is an abstract, squared-off `C`. Its open right side suggests a framework that can be extended and adapted. The inset square represents a building block or documented component.

## Usage
- Prefer the symbol + wordmark lockup for repository headers and social assets.
- Use `symbol.svg` for compact placements.
- Use `favicon.svg` on dark browser surfaces.
- Keep clear space around the mark equal to at least the inset square's width.
- Do not stretch, rotate, add shadows, add gradients, or change the yellow accent.
- On light backgrounds, use `logo-light.svg`; on dark backgrounds, use `logo-dark.svg`.

## Palette
| Token | Hex |
|---|---|
| Yellow | `#FBBF24` |
| Dark | `#1F1F23` |
| Gray | `#6B7280` |
| White | `#F9FAFB` |

## Tone
Precise, practical, open, developer-focused. Avoid decorative effects and unnecessary visual noise.

Tagline: **Craft better. Document smarter.**
