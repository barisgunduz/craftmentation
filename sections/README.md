# Reusable README sections

The [catalog](../templates/catalog.json) defines each fragment's stable identifier,
standard classification, order, source path, and required authoring fields.

- `core/` contains Project name, Description, Overview, and Usage information.
- `optional/` contains every non-Core item, including Recommended and Project-specific
  sections. Its directory name does not replace the catalog classification.

Fragments are building blocks, not finished project claims. Consult the
[standard](../docs/standard.md) and [library contract](../docs/templates.md), select only
relevant verified content, fill fields manually, and remove authoring comments before
publication. Retain required notices and preserve the target project's actual license.
