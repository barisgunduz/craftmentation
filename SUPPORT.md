# Support

Craftmentation provides a local CLI MVP and manually adapted documentation materials.
The CLI supports init, analyze, generate, and offline validate. Advanced updates,
translations, a hosted documentation site, and a public package release are not available yet.

## Find guidance

Start with the [README](README.md), [draft standard](docs/standard.md),
[README template](README.template.md), and [roadmap](docs/roadmap.md).
For proposed contributions, read [CONTRIBUTING.md](CONTRIBUTING.md).

## Questions, bugs, and ideas

Search [GitHub Issues](https://github.com/barisgunduz/craftmentation/issues) first.
If no existing issue addresses your question, open one with a descriptive title.
Use the bug report or feature request template when applicable; a plain issue is
appropriate for usage questions. GitHub Discussions is not enabled.

Include the affected file and repository revision, what you were trying to accomplish,
what happened, and a small sanitized example. State which checks you ran. Share only
information you have permission to publish; omit secrets and private project content.

Support is provided as maintainer availability permits, with no guaranteed response time.
For vulnerabilities follow [Security](SECURITY.md), and for conduct concerns follow the
[Code of Conduct](CODE_OF_CONDUCT.md#reporting). Public issues are not a confidential channel.
