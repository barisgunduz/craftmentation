# Contributing to Craftmentation

Thanks for your interest in improving Craftmentation.

## Before you start

- Check existing issues and discussions to avoid duplicate work.
- For substantial changes, open an issue first to discuss the proposal.
- Keep changes focused and explain the problem they solve.

## Contribution guidelines

- Prefer clear, portable Markdown.
- Keep the core standard broadly applicable.
- Put project-specific or optional guidance in `sections/` rather than making the core README longer.
- AI instructions must be tool-agnostic unless they belong in a tool-specific file.
- Never add undocumented assumptions or fabricated examples.
- Include examples or validation notes when changing a template or standard.

## Pull requests

A pull request should describe:

1. What changed
2. Why the change is needed
3. Which files or standards are affected
4. How the change was checked

## Style

Use concise, direct language. Prefer practical examples over abstract claims. Keep headings descriptive and avoid decorative clutter.
