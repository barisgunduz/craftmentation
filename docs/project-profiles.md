# Project profiles

Craftmentation should adapt its README to the kind of repository being documented.

Initial profiles to support:

- Web application
- Mobile application
- Desktop application
- CLI tool
- API / backend
- Library / SDK
- SaaS
- AI / machine learning
- Research project
- Developer tool

Profiles should recommend relevant sections, not force them. For example, a library may need API reference and compatibility details, while a mobile app may need platform requirements and store links.
